How to publish it (no local tools needed)

  1. Open the repo in the browser editor: github.dev editor (the file is ~3 MB, too big for the normal github.com editor; github.dev handles it).
  2. In grants.json, go to the very end of the file. Before the final ] that closes the list, add a comma after the last entry's closing }, then paste the generated entry.
  3. Near the top of the file, set "lastUpdated" to today.
  4. Commit from the Source Control icon in the left sidebar (message like Grant Desk: add ..., no Co-Authored-By lines).
  5. Feeds, calendars and SEO pages regenerate automatically: the daily Publish queued grants workflow runs at 06:00 UTC and commits the regenerated files. To publish immediately, open that workflow and press "Run workflow". The entry itself shows on the site as soon as GitHub Pages deploys your commit; only the feeds wait for the workflow.
